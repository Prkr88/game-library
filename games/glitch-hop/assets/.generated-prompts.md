# Glitch Hop generated asset prompts

Built-in image generation used. Every prompt begins with the shared style block from `ASSET_PROMPTS.md`; transparent assets request genuine alpha, centered subject, no text/watermark, no exterior drop shadow, and top-left lighting. Character animation frames reference `player-idle-1.png` to lock design while changing only pose. Final canvases are resized to exact requested dimensions with nearest-neighbor filtering.
